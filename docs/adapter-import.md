# Adapter import

Only adapter data from the supplied adapters.zip was read. No legacy application code, scraping functions, validation exceptions, prompts or workflow instructions were imported. Original product and tier IDs, aliases, lifecycle states and explicit URLs are retained. All discovery flags default to false. Source topics are hints, not evidence. Legacy region labels are retained as identity metadata; they do not assert country membership.

Explicit physical/virtual manual facts for Picnic and Ruvo are retained with an import note and date. Ruvo's legacy country-complement policy is **not** a provider-confirmed eligibility list: its exclusions (AF BY MM CF CU CD IR IQ LB LY ML NI KP RU SO SS SD UA VE YE CN HK) are recorded here for human review, not published as availability. Financial values encoded in conditional scraping code are not accepted facts and must be re-extracted with citations by the universal agent. Old per-provider derivation and removal instructions are not executed.

Provider website is initially the origin of its configured product page (or first source); review branding URLs as needed. These are imported adapters, not a completed live extraction benchmark.
